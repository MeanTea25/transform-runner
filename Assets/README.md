# Transform Runner

A three-level 3D obstacle course built in Unity that demonstrates vectors, coordinate systems and linear transformations (translation, rotation, scaling).

**Developer:** Rojer Victor C. Nuqui
**Course:** Applied Mathematics for Games

## How to run
Open this folder in Unity Hub, open `Assets/Scenes/MainMenu`, and press Play.

## Controls
| Key | Action |
|---|---|
| W A S D | Move (translation) |
| Space | Jump |
| X (hold) | Rotate the character (Shift reverses) |
| Y (hold) | Scale the character (Shift shrinks) |
| K | Cycle speed mode: Normal / Boost / Slow |
| Q / E | Orbit camera |
| Esc | Pause |

## Features
- Custom-built 3D robot character (no default primitives), with walk and jump animation
- 3 levels: Meadow Run, Scorched Canyon, Neon Frostbite
- Static obstacles, spike traps, spinning blades, turret projectiles
- Patrolling enemies with waypoint (ping-pong and loop) movement
- Main menu, level select and about screens
- Live transformation HUD showing scale, rotation, speed mode and velocity
